# Jenny assistant verification

Enable Jenny through the Cellarium tray context menu: Enable Assistant. Click her to ask a question. Right-click for outfit, idle behavior, sarcasm, placement and Disable.

- 25 assistant test groups passed, including real quantized CPU inference, asynchronous classification, repeated native-library restarts, current-state diagnostics and 111 sprite frames.
- 37 question cases: 34 expected outcomes, 3 cautious abstentions, 0 wrong accepted intents.
- 30 additional question cases: 25 expected outcomes, 5 cautious abstentions, 0 wrong accepted intents. These finite suites were used during development and do not prove perfect English understanding.
- 13 growth integration groups passed, including the 1,000-organism generation audit and movement physiology.
- Desktop regression: 53 checks passed. Existing workstation, equipment and DNA tests retained.
- Initial interactive native assistant baseline: 5 checks passed across monitors. The final expanded six-check native pass could not run because computer-use access reached its request limit; the final outfit/scaling behavior was verified through headless rendering and state tests.
- Physical non-AVX hardware was unavailable. SSE2 baseline and guarded AVX dispatch were inspected in the official runtime source; actual old-processor testing remains unverified.

Movement explanations use freshly computed anatomical controller results, not just cached capability flags. Genome forecasts call the actual expression and generator APIs. Unknown or incomplete data produces clarification rather than a biological story. Replies use authored facts and personality templates; MiniLM only matches questions.
