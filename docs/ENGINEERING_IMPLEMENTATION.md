# Inventory, delivered slice and next milestones

## Existing systems inspected and preserved

All existing Lua modules and entry points were inventoried before this branch changed. The baseline provides 24 chromosome pairs with three loci each; canonical alleles, seeded mutation, lab fusion and haploid reproduction; bounded growth operations, connected anatomy and real tissues; regional coverings, respiration and projections; physiology, habitat navigation, seven cell categories, cultures, cryostorage, research, version-4 manual saves, audits and tested portable builds.

Missing foundations were DNA procurement, multi-source editable genome libraries, blank-cell installation, six live biological summaries, individual memory/relationships and a shared future desktop/AI organism interface. The old Nature axis had no learned state. The old three-donor interface was restrictive as the primary construction workflow. Ecological balancing was already unfinished.

## Delivered vertical slice

- Persistent DNA vials with seed, identity, chromosome genome, modeled allele sequence, purchase budget and sequencing assay findings.
- Whole-genome construction from one or more sources, including six in tests/audits, without species presets.
- Corresponding-locus splicing, mutation, dosage duplication/deletion/restoration and nonrecursive activating/suppressing links. Names, history, archives and independent reuse are implemented.
- Shared expression across all three locus families. Dosage and regulatory metadata travel through gametes and fertilization.
- Single blank-cell installation enters real embryo development; batches produce six matched stem cells for the existing culture rules.
- Aggregate embryonic proliferation, stage history and nutrient demand/use records connect to the existing growth grammar. Default supplies are implicit; finite embryo resource exhaustion is not implemented.
- Dynamic STR/DEF/DEX/INT/VIT/END derived from actual anatomical and physiological quantities. Initial cardiac/blood transport records can produce failure independent of generic health.
- Continuous inherited/developed predispositions, neural memory/recognition gates, bounded perceived memories, reinforcement/forgetting and remembered feeding outcomes.
- Actual sensory-range encounters create directional familiarity/trust/fear. Needs, current stress and memories can influence otherwise-idle behavior. Basic mate search is sensory bounded and learned trust can reduce avoidance.
- Structured nonverbal signals and same-entity organism snapshots/serialization, with narrowly validated future biological intents. No external model or desktop host is invoked.
- Separate version-5 state/save identity; version 2–4 data migration remains supported. Old artifacts and main remain intact.
- Forty-six regression groups, current UI workflow and a measured 1,000-genome/cohort/performance audit.

## Remaining work: not claimed complete

1. Richer experimental gene discovery, arbitrary fragments, edited-genome recombination UI, reversible edit transactions and sustainable laboratory economy.
2. Finite embryo energy/nutrient stores, genetically varied stage timing, organ-specific maturation, actual tissue remodelling and lifetime conditioning. Current growth uses aggregate stages and the existing effective growth fraction.
3. More causal organ-specific pathology, diffusion-only viability and distributed transport. Conditional vital records exist, but current generated bodies still normally develop a central pump.
4. More contrasting-behavior experiments, conditioned threats, social learning, routines, object associations, manipulation knowledge and planning based consistently on observed/remembered terrain. Existing map navigation is retained.
5. Actual specialized sound/light signaling anatomy and richer learned communication. A high cognitive summary must not imply speech.
6. Optional offline-model integration behind simulation-owned capability validation.
7. Separate desktop rendering/input host, multi-monitor geometry and recall using the same organism state. No unrestricted application/file control.
8. Longer multi-generation balancing, stress/injury-driven social studies, larger-population profiling and more migration fixtures.

Combat remains deferred under the user's existing constraints. Future examples of fighting in the prompt are not presented as a completed battle system.
